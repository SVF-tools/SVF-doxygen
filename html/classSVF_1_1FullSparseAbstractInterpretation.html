JOIN only the selected Obj IDs from src into dst; missing values contribute nothing. The caller selects base/sub Objs and handles path constraints and strong/weak updates. ValVars and freed addresses are not copied here. Memory lookups use AbstractState's existing address resolution, including its freed-address handling.
