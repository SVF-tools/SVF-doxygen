Filter one SVFG input using branch-feasible ICFG paths. int x = input(); // D: x=[0,10] if (x > 5) { // B use(x); // N: this path contributes x=[6,10] } See the implementation for D/B/N patterns at each decision branch, including conservative call/global handling and path/loop merges. A local worklist JOINs inputs at visited ICFG nodes, not whole paths. It does not execute arithmetic or cache results across WTO iterations. Along the path, reuse computed Store results only for carried Objs; shared isStrongUpdate selects replacement versus conservative JOIN.
