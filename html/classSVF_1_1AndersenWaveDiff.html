◆ postProcessNode()

void AndersenWaveDiff::postProcessNode ( NodeID nodeId)
virtual

Post process node: add the copy edges of its loads and stores. For x = *p, growing pts(p) from {a} to {a, b} only needs the new copy b -> x. A load or store edge already handled at this node needs only the objects added to the node's points-to set since then; an edge new at the node (e.g. moved here by an SCC merge) needs all of them. Endpoints identify each constraint even when its edge is recreated.
