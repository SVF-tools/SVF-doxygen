Detailed Description

Prebuild Obj routes from SVFG object information and ICFG order. Fields and array elements of the same base are packed on one route: D: a[0] = 1; S: a[1] = 7; N: use(a[0]); Program order gives D -> S -> N, rather than two independent packed inputs from D and S. Bases that share a route segment share one labeled edge: S1: *p = 1 (p -> {a,b}); S2: *q = 2 (q -> {a,b}) gives one edge S1 -{a,b}-> S2. A branch edge gets one node, but the graph neither computes nor stores intervals; clients check feasibility and refine values.
