Detailed Description

Prebuild Obj routes from SVFG object information and ICFG order. Fields and array elements of the same base are packed on one route: D: a[0] = 1; S: a[1] = 7; N: use(a[0]); Program order gives D -> S -> N, rather than two independent packed inputs from D and S. A branch edge gets a synthetic node, but the graph neither computes nor stores intervals; clients check feasibility and refine values.
